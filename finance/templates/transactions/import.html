The import is all-or-nothing: if any row has a problem, nothing is saved.

File format

The first row must be headers. Required: date, description, amount.

  • type - income, expense or transfer. If left out, negative amounts are expenses and positive amounts are income.
  • category, account, to_account (for transfers), notes - optional.
  • Dates: YYYY-MM-DD or DD/MM/YYYY.
